# Salkku Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A private "Salkku" post type in wp-admin that holds Sami's owned apartments, shows the Excel's five totals and apartment table per owner and combined, and offers MCP-only abilities to read, create and update apartments.

**Architecture:** `ketunkoti-features` gets a pure calculator, the closed post type `portfolio` with taxonomy `portfolio-owner` and `portfolio_*` meta, a classic meta box and a PHP-rendered overview page. `ketunkoti-ai` gets a Registrar option for MCP-only tools and a `Portfolio_Abilities` class. Data is entered locally through the new create ability.

**Tech Stack:** WordPress 7.1 (wp-env), PHP 8.2, Abilities API, MCP Adapter v0.7.1, WP-CLI `eval-file` test harnesses.

**Spec:** `docs/superpowers/specs/2026-11-22-salkku-design.md`

## Global Constraints

- No real portfolio figures, addresses or apartment names in code, tests, docs or commit messages. Tests use invented numbers.
- No public path: no front-end output, no REST route for the post type, no sitemap, no search, no feed.
- Post type key `portfolio`, taxonomy `portfolio-owner`, meta prefix `portfolio_`, everything gated by `manage_options`.
- Portfolio abilities are MCP-only: not `meta.public`, not in the Seravo chat.
- Finnish UI strings, text domains `ketunkoti-features` / `ketunkoti-ai`, 4-space indentation, PHPDoc on every function.
- Node commands: `source ~/.nvm/nvm.sh && nvm use` first. wp-env commands run from `/Users/samikeijonen/projects/ketunkoti`.
- Test command shape: `npx wp-env run tests-cli wp eval-file wp-content/plugins/<plugin>/tests/php/<file>.php` → last line `ALL PASSED`.
- No commits: Sami commits himself at the end. Before Task 1, ask Sami about a worktree and a feature branch (from `main`, e.g. `feature/salkku`) per his global instructions.

## Review Focus

1. Finnish-formatted numbers ("1 285,50", non-breaking space thousands) in the meta box and the abilities are accepted, not truncated. → Task 3 and Task 6 tests.
2. An apartment with no owner term is shown under "Ei omistajaa" and counted in the combined totals. → Task 4 test.
3. A draft apartment is left out of every total but listed under its owner's table. → Task 4 test.
4. The overview with zero apartments renders without PHP warnings, leverage "–". → Task 4 test.
5. `portfolio_home_id` pointing at a non-`home` post or a deleted post is refused on save. → Task 3 test.
